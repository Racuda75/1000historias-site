# 1000historias.com

Sitio estático de 1000 Historias, publicado con GitHub Pages en el dominio propio 1000historias.com.

- Español en `/`, inglés en `/en/`.
- Todos los recursos (imágenes, fuentes, videos, scripts) están dentro de `/assets/`.
- El formulario de contacto envía a FormSubmit (1000historiaswines@gmail.com).
- `CNAME` define el dominio y `.nojekyll` evita que GitHub procese el sitio con Jekyll.
